## 接入 Tailwind CSS v4
- 项目：Vite 8 + React 19 + TS 7（`my-react-app`），包管理器实际用 npm（bun 未安装，`bun.lock` 存在但不可用）。
- 方案：Tailwind v4 官方 Vite 插件路线，无 `tailwind.config.js`、无 PostCSS 配置。
  - 安装：`@tailwindcss/vite@4.3.5`、`tailwindcss@4.3.5`（装进了 dependencies）。
  - `vite.config.ts`：`plugins: [react(), tailwindcss()]`。
  - `src/index.css` 首行：`@import 'tailwindcss';`（原有模板变量样式保留在下方，作为覆盖层）。
- 验证：`npm run build` 通过；临时加 `bg-red-500` 探针确认工具类能生成；产物 CSS 含 preflight（`box-sizing:border-box`、`--tw-`）。探针文件与临时 tsconfig 已删除。
- 坑：编辑 `vite.config.ts` 时文件末尾被写入了两个多余反引号 `` ` ` ``，导致 `tsc -b` 报 `TS2349: Type 'UserConfig' has no call signatures`（误导性报错）。用 Write 重写整文件解决。后续改配置文件若遇到诡异类型错误，先 `od -c` 看有没有脏字符。

## 修复：工具类被模板样式压住（text-red-500 不生效）
- 现象：`<h1 className="text-red-500 text-3xl font-bold">` 完全无效。
- 原因：Tailwind v4 把工具类放进 `@layer utilities`，而 **unlayered CSS 永久优先于任何 @layer，与选择器权重无关**。模板 `index.css` 里的 `h1, h2 { color/font-size/font-weight }` 写在层外，因此同时压掉了 `text-red-500`/`text-3xl`/`font-bold`。
- 解决：项目自有样式全部入层——`src/index.css` 除首行 `@import 'tailwindcss';` 外整体包进 `@layer base`；`src/App.css` 整体包进 `@layer components`（层顺序由 tailwind 的 import 声明：theme→base→components→utilities）。
- 验证：`npm run build` 通过；`vite preview` + Chrome `--headless=new --screenshot` 截图确认标题变红、字号 30px、加粗，其余布局无回归。临时文件已删。
- 约定：后续新增自定义全局样式务必写进 `@layer base`/`@layer components`，否则会再次压住工具类。
