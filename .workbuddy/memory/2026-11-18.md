# 2026-11-18

## 首页改造：`/` 交给 `src/routes/home.tsx`，移除 `src/App.tsx`
- 背景：用户把 `App.tsx` 原样复制/拖进 `src/routes/home.tsx`，但那份文件不是合法路由文件（相对路径 `./assets/*` 失效、无 `createFileRoute` 导出、默认导出名还是 `App`），且 `index.tsx` 仍 `import App from '../App'`。
- 改造方案（采用「/home 为真实首页 + / 重定向」）：
  - `src/routes/home.tsx`：加 `createFileRoute('/home')`，组件改名 `Home`；资源引用改 `../assets/hero.png`、`../assets/react.svg`、`../assets/vite.svg`、`../App.css`（`App.css` 保留在 `src/`，未删）。
  - `src/routes/index.tsx`：改为 `beforeLoad: () => { throw redirect({ to: '/home' }) }`（TanStack 官方推荐的 index 重定向写法，无需 component）。
  - `src/routes/__root.tsx`：导航 Home 链接由 `to="/"` 改为 `to="/home"`。
  - `src/routes/about.tsx`：`router.navigate({ to: '/', params: { id: 1 } })` → `router.navigate({ to: '/home' })`（原 `params` 对无参数路由无意义）。
  - 删除 `src/App.tsx`（仅 `index.tsx` 引用，无其他依赖）。
- 顺手修复：`src/main.tsx` 里 `<RouterProvider router={} />`（用户误删变量名导致 esbuild/rolldown 解析失败），补回 `router={router}`。
- 验证：`npx tsc -b` 零错误；`npx vite build` 通过且产出 `home-*.js`、`about-*.js` 独立 chunk；`routeTree.gen.ts` 的 `fullPaths` 为 `'/' | '/about' | '/demo' | '/home'`；preview 下 `/ /home /about /demo` 均 200（SPA fallback 正常）。
- 环境坑：
  - Chrome `--headless=new --screenshot/--dump-dom` 在本机无任何输出（EXIT=0 但文件为空），无法做截图验证，改用构建产物 + HTTP 状态码验证。
  - `vite build` 报 `[safe-delete][SAFE_DELETE_BULK_GUARD_ERROR] ... ETIMEDOUT`：不是代码问题，是 `dist/` 被正在跑的 `vite preview` 占用，Windows 下删不掉。**构建前先停掉 preview 进程**。

## 调整（同日二次）：`/` 直接渲染 home 页，取消 `/home`
- 需求变更：用户要求访问 `/` 就是 home，不要重定向到 `/home`。
- 关键约束：TanStack 文件式路由**路径由文件名决定**，`/` 只能由 `index.tsx` 承载，`home.tsx` 永远只能映射 `/home`。想让 `/` 显示 home 内容，必须把内容放进 `index.tsx`。
- 做法：
  - `src/routes/index.tsx`：整份 Home 页面（`createFileRoute('/')` + `component: Home`），资源引用保留 `../assets/*`、`../App.css`；正文里的提示文案改为 `src/routes/index.tsx`。**按用户当时已精简的版本落地**（他删掉了 next-steps 里的链接列表），不要用自己早先那版覆盖。
  - 删除 `src/routes/home.tsx`（与 index 重复且只剩 `/home` 一条无用路由）。
  - `__root.tsx` 导航 Home → `to="/"`；`about.tsx` 的 Go Home → `to: '/'`。
- 验证：`tsc -b` 零错误；`vite build` 通过；`routeTree.gen.ts` 的 `fullPaths` 变为 `'/' | '/about' | '/demo'`，`/home` 完全消失；源码内 `/home` 残留为 0；产物 `dist/assets/routes-*.js` 内含首页文案「Get started」（index + __root 进了同一个 routes chunk，属正常）。
- 备注：`/home` 现在会落到 NotFound；若日后要兼容旧链接，可新建 `home.tsx` 写 `beforeLoad: () => { throw redirect({ to: '/' }) }`。
