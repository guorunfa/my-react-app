# 2026-11-17

## 修复 TanStack Router 报错 `Argument of type '"/demo"' is not assignable to parameter of type 'undefined'`
- 现象：`src/routes/_root.tsx` 里 `createFileRoute('/demo')` 报 TS2345，参数类型被推断成 `undefined`。
- 根因（三层，逐层暴露）：
  1. `vite.config.ts` 插件顺序错误：`react()` 在 `tanstackRouter()` 之前。router 插件在 `configResolved` 阶段直接抛「Plugin order error」，所以 **`routeTree.gen.ts` 从未生成**。
  2. `routeTree.gen.ts` 缺失 → `FileRoutesByPath` 为空接口 → `createFileRoute<FilePath extends keyof FileRoutesByPath>` 的合法路径联合为空 → 可选参数退化为 `undefined`，故出现这个误导性报错（不是 `/demo` 写错）。
  3. 缺少必需的 `__root.tsx`；且 `_root.tsx`（单下划线）在文件式路由里表示 **无路径布局路由**，其 id 只能是 `/_root`，不能承载 `/demo`。
- 解决：
  - `vite.config.ts` 改为 `plugins: [tanstackRouter({target:'react',autoCodeSplitting:true}), react(), tailwindcss()]`（顺序有注释标注）。
  - 新建 `src/routes/__root.tsx`（`createRootRoute` + 导航 + `<Outlet />`）、`src/routes/demo.tsx`（`/demo`）、`src/routes/index.tsx`（`/` → 复用 `App`）。
  - 删除 `src/routes/_root.tsx`。
  - `src/main.tsx` 改为 `createRouter({routeTree, defaultPreload:'intent'})` + `RouterProvider`，并加上 `declare module '@tanstack/react-router' { interface Register { router: typeof router } }`（类型安全/预加载必需）。
- 验证：`npx vite build` 通过并生成 `src/routeTree.gen.ts`（含 `/` 与 `/demo`）；`npx tsc -b` 零错误。
- 约定：新增页面只需在 `src/routes/` 下建文件，路径即路由；`_xxx.tsx` = 无路径布局，`xxx.$id.tsx` = 动态段。改路由文件后 dev/build 会自动重生成 `routeTree.gen.ts`，需提交入库。
